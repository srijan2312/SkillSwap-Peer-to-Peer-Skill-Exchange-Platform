# SkillSwap — Peer-to-Peer Skill Exchange Platform

> A full-stack platform where people exchange skills instead of money.

SkillSwap connects people who want to **teach what they know and learn what they need**. Users create profiles, list skills they can teach and want to learn, discover compatible partners, send skill-swap requests, complete exchanges, and build reputation through reviews and ratings.

## 📌 Overview

Traditional learning platforms usually involve paying for courses or instructors.

SkillSwap takes a different approach:

> **Exchange knowledge instead of money.**

For example:

**User A**

- Can teach: React, JavaScript
- Wants to learn: Docker, AWS

**User B**

- Can teach: Docker, AWS
- Wants to learn: React, JavaScript

SkillSwap identifies the compatibility between them and allows them to exchange skills.

The platform supports the complete workflow:

```text
Create Profile
      ↓
Add Skills
      ↓
Discover Partners
      ↓
Find Matches
      ↓
Send Swap Request
      ↓
Accept / Reject
      ↓
Complete Swap
      ↓
Leave Review
